A full-stack web app for guitarists that packs five tools into one: an interactive Fretboard Playground for chords and scales, a Scale Practice drill mode, a real-time mic-based Tuner, an adjustable Metronome, and an effects Pedal Board for shaping tone — driven by the Web Audio API for low-latency sound.
